RMBS Waterfall & Stress Lab

Monthly cash flow waterfall for a four-class deal with excess spread, overcollateralization, a stepdown date and a cumulative loss trigger. Compare base, moderate and severe scenarios and see which classes take losses.

Loan Tape Analyser

Load an Excel or CSV tape, map it to standard field names, add Excel-style calculated fields, filter the pool, define measures such as SUM, AVG, COUNT and balance-weighted averages, and build custom strats exported to Excel. A Python version adds data quality checks and a Claude-drafted collateral commentary.

How these were built

I describe the deal mechanics, trigger definitions and test formulas the way I would brief a new analyst, use Claude to turn them into working code, then validate the results against hand calculations and my own expectations before iterating. All data here is synthetic.
