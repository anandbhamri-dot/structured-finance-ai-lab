Loan Tape Analyser

Tape cracking, calculated fields and stratifications for securitised loan pools

Load a loan tape from Excel or CSV, map its columns to standard field names, define aggregate measures such as SUM, AVG, COUNT and balance-weighted averages, and build the stratification tables you need. Add loan-level calculated fields here, or in Excel before loading. Everything runs in your browser, and the tape never leaves your computer.

Templates

A template saves your whole setup: manual field mappings, calculated fields, pool filter, measures and strats. It holds no loan data. Set up one tape, save a template, then load it on the next tape to rebuild everything in one step. You can load a template before or after the tape.

Templates saved in this browser stay on this computer and browser only, and are deleted if you clear browser data. Download a file to back one up or share it with a colleague.

1. Load tape

Excel (.xlsx, .xls) or CSV, one loan per row, column headers in the first row. Excel formulas are read as their calculated values, so save the file in Excel after adding calculated columns.

Off by default. When on, the loan data stays in this browser on this computer until you clear it or untick the box. Use it only on your own computer.

2. Map fields

Columns are matched to standard field names automatically; change any mapping in the dropdown. Unmatched columns are kept as custom fields under a capitalised name, so they can still be stratified and aggregated. Percent fields supplied as decimals (0.75) are converted to percent (75).

3. Calculated fields

Add new columns or edit existing ones with Excel-style formulas, calculated loan by loan. Steps run in order, so a step can use fields created above it. Original values are kept: switch a step off or delete it and the column reverts to the uploaded tape.

Function reference

Operators: + − * / ^ (power), & (join text), = <> < <= > >=. Text goes in quotes, e.g. "Current". Field names are used as written (PRIN_BAL), or in brackets for any name: [PRIN_BAL]. Text comparisons ignore case, as in Excel. A blank input gives a blank result, and a row that can't be calculated (e.g. division by zero) is left blank and counted as an error.

Aggregates: SUM, AVG, MIN, MAX, MEDIAN and COUNT with a single field name work on the whole column, as an Excel column reference would, e.g. IF(PRIN_BAL > AVG(PRIN_BAL), "Above average", "At or below"). With several values they work loan by loan, e.g. MAX(FICO - 600, 0). GROUP_ functions return the figure for the loan's own group, e.g. PRIN_BAL / GROUP_SUM(PRIN_BAL, STATE). Aggregates use every loan in the tape as it stands at that step, before the pool filter; loans with a blank group value get a blank result.

4. Pool filter

Optional. Restrict the pool before anything is calculated, e.g. current loans only, or FICO of at least 660 excluding investor properties. Measures, strats and "% of pool" figures all use the filtered pool. Blank values only match "is blank".

5. Measures

Aggregate calculations available as strat columns. Weighted averages are weighted by any numeric field, usually PRIN_BAL. A measure that needs a field missing from the tape is greyed out.

Add a measure

6. Strats

Each strat groups the pool by one field. Choose distinct values (with an optional top-N and "Other" bucket), numeric breakpoints, or year for date fields, then pick and order its columns. Save the whole set as a template to reuse on the next tape.
